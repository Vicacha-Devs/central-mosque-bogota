03. Fixed Bottom Interaction

Implementation Pattern

For mission-critical actions like donations or emergency prayers, we use a high-contrast fixed bottom bar. On mobile, this bar overlaps the content with a subtle glassmorphism or solid background to ensure legibility.

.fixed-bottom-cta { position: fixed; bottom: 0; padding: 16px; background: #fff; z-index: 100; }
  • Minimum 16px safe area from device edges.
  • Z-index must be higher than any scrollable content.
  • Use shadow-up for depth against page content.
