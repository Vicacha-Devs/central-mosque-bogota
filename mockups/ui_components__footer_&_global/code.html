RTL Architecture Note

All global components are engineered with logical properties (e.g., `ps-4`, `me-2`) to ensure seamless transition when Arabic is selected. The footer layout is designed to mirror horizontally, with "Mezquita Central" logo moving to the top-right position and navigation links flowing right-to-left.
