# Typography

The site uses two text families and one icon font, all registered in
[`astro.config.ts`](https://github.com/Vicacha-Devs/central-mosque-bogota/blob/main/frontend/astro.config.ts)
through the Astro Fonts API (Fontsource provider).

| Role    | Family                    | CSS variable     | Tailwind class | Weights                    |
| :------ | :------------------------ | :--------------- | :------------- | :------------------------- |
| Display | Plus Jakarta Sans         | `--font-display` | `font-display` | 400, 500, 600, 700, 800    |
| Sans    | Public Sans               | `--font-sans`    | `font-sans`    | Fontsource defaults        |
| Symbols | Material Symbols Outlined | `--font-symbols` | n/a            | Variable (see Iconography) |

`font-display` is applied to `<body>` in `Layout.astro`, so it is the default for all
text. Use `font-sans` only where Public Sans is wanted explicitly.

## Arabic (RTL)

The Arabic locale renders right to left. Use logical utilities (`text-start`, `ps-*`,
`ms-*`) so layouts mirror automatically, and check Arabic copy on real pages: it falls
back to the platform font when the web font has no matching glyphs.

<div dir="rtl" lang="ar">
  <Typeset
    fontFamily={DISPLAY}
    fontWeight={700}
    fontSizes={[24, 36]}
    sampleText={SAMPLE_AR}
  />
</div>

## Guidelines

- Prefer the Tailwind scale (`text-base`, `text-xl`, …). Avoid arbitrary pixel sizes.
- Keep body copy at `text-base` or larger, with `leading-relaxed` for long paragraphs.
- Use weight, not extra sizes, for hierarchy inside a component: `font-medium` for
  labels, `font-semibold` for headings, `font-extrabold` only for hero titles.
- Cap long-form line length near 65 characters (the `Prose` component already does).
