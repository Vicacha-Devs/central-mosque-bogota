# Colors

Every color in the interface comes from a semantic token defined in
[`src/styles/global.css`](https://github.com/Vicacha-Devs/central-mosque-bogota/blob/main/frontend/src/styles/global.css).
Each token is exposed as a Tailwind utility (`bg-primary`, `text-muted-foreground`,
`border-border`, …), so components never reference raw palette values.

The swatches below read the live CSS variables. Switch between **light** and **dark**
in the toolbar and they update with the theme.

## Usage rules

- Use the semantic token, not a Tailwind palette color: `bg-primary`, not `bg-red-700`.
- Always pair a surface with its foreground (`bg-primary` with `text-primary-foreground`).
- Dark mode needs no `dark:` color overrides. The tokens already change under
  `[data-theme="dark"]` / `.dark`. Reserve `dark:` for one-off cases such as images.
- Do not rely on color alone to convey state. Combine it with an icon or text.
