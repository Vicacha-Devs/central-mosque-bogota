# Typography · Plus Jakarta Sans & Public Sans

Central Mosque of Bogotá pairs **Plus Jakarta Sans** (`--font-display`, weights `400`–`800`) for display headlines and section titles with **Public Sans** (`--font-sans`) for body copy, UI controls, and multilingual (`es`, `en`, `ar`, `tr`) layouts.

export const typography = {
  type: {
    display:
      '"Plus Jakarta Sans", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif',
    sans: '"Public Sans", ui-sans-serif, system-ui, -apple-system, "Segoe UI", sans-serif',
  },
  weight: {
    regular: "400",
    medium: "500",
    semibold: "600",
    bold: "700",
    extrabold: "800",
  },
  size: {
    display: 48,

    headline: 30,
    title: 24,
    lead: 20,
    body: 16,
    bodySm: 14,
    label: 12,
  },
};
